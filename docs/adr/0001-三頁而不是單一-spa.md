# ADR 0001 — 三頁，而不是一個合併的 SPA

日期：2026-09-13
狀態：已採納

## 背景

英文與日文的 app 已經在 artifact 環境做好了，各自是一份 1,300 行、
內含 React（CDN）與完整 CSS 的獨立 HTML。架構文件寫的是「單一 PWA，
內部切換英／日／泰，共用一份引擎程式碼、三份語言設定檔」。

照文件做，就要把兩份能動的程式碼拆開、抽出共用引擎、再重組回去。

## 決定

**三頁**：`/en/`、`/ja/`、`/th/`，各自是一份幾乎原封不動的 HTML，
masthead 加一條語言切換列。共用的部分只有 `shared/ll.js`（呼叫 API 與發音）。

## 理由

1. **文件要的「單一 PWA、一個圖示」仍然成立。** 一個 manifest、一個 scope、
   一個 start_url，切語言只是同源導覽。使用者感受不到差別。
2. **抽共用引擎的收益是假的。** 三個語言的課程 JSON 形狀不同
   （英文有 ipa、日文有 kana/accent/tokens、泰文有 rom/tone/tokens），
   渲染器要嘛塞滿條件分支，要嘛被設定檔的間接層繞一圈。真正重複的
   只有 CSS 和 React 樣板，那些重複不會痛。
3. **風險不對稱。** 重寫會動到兩份**已經在用、已經驗證過**的程式碼；
   加一條語言列不會。
4. 三份 63KB 的 HTML 對 Cloudflare Pages 完全不是問題。

## 代價

- 切語言會重新載入頁面。課程存在 localStorage，狀態不會掉，實際上感覺不出來。
- CSS 與 React 樣板在三份檔案裡重複。改共同的視覺要改三次。
  真的開始痛的時候再抽，不要現在抽。
