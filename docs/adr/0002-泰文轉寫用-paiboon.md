# ADR 0002 — 泰文轉寫用 Paiboon，不用 RTGS

日期：2026-09-13
狀態：已採納（泰文版尚未實作，但先定案）

## 背景

泰文要挑一套羅馬轉寫系統並貫徹到底，不能讓模型每次換一種拼法。
主要候選是 RTGS（泰國皇家學會官方系統）與 Paiboon。

## 決定

**Paiboon**，含聲調附加符號。

## 理由

1. **RTGS 完全不標聲調。** 泰文有五個聲調，聲調是這個語言最難的一關，
   也是學習者最需要外部提示的地方。用一套不標聲調的系統，
   等於把最難的部分從教材裡拿掉。
2. **跟既有的泰文字卡庫一致。** `~/Developer/thai` 的 3,132 張卡
   `romanization` 欄位全部是 Paiboon（`sà-wàt-dii`、`kɔ̀ɔp-kun`、`bpai`）。
   同一個人同時學兩套轉寫只會互相干擾。
3. Paiboon 區分送氣與不送氣塞音（ก=g 對 ค=k、ป=bp 對 พ=p），
   RTGS 把 ก 和 ค 都寫成 k。對要開口說的人，這個區分是必要的。

## 做法

prompt 裡給明確規則與九組對照範例，並要求 `tone` 欄位用中文聲調名
（中平／低／降／高／上升）逐音節標出，數量必須跟音節數一致。
聲調名沿用 `thai/apps/flashcards/server/src/tone.ts` 的 `TONE_INFO`。

## 代價

Paiboon 用了 ɛ、ɔ、ɤ、ʉ 這些 IPA 符號，對完全沒接觸過的人第一眼比 RTGS 陌生。
但學會這幾個符號是一次性成本，聲調記錯是每天的成本。
